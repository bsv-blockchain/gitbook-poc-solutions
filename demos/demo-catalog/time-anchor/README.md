# Time Anchor

Put checksums on the blockchain to verify integrity of applications, but expanded to include Overlay Services to register the files and keep track with UHRP / BRC-26 and StorageUploader and use WalletClient from @bsv/sdk to make use of BSV Desktop for making transactions.
